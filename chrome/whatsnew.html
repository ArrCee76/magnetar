What's new

History is more useful now

You can resend previous items, open the original source URL when available, and remove individual history entries.

Recent sends in the toolbar

The toolbar now shows up to your last 20 sends, so you can quickly check recent activity without opening the full settings page.

New help page

A new Help button opens the Magnetar Help page with a toolbar guide, setup help, batch mode tips, target explanations, privacy notes, and troubleshooting.
